# Spécification UI/UX - CleanTrack Pro

## 1. Identité Visuelle
* **Couleur Primaire :** Bleu Trust (#1A5AD7) - Professionnalisme.
* **Statut Express :** Orange/Rouge avec icône éclair (⚡).
* **Disponibilité Rayon :** Vert (Libre), Gris (Occupé).

## 2. Écrans Principaux
### A. Dashboard Admin (Vue SaaS)
* Cartes KPI : CA Global, Dépenses, Marge Nette.
* Sélecteur de Site pour filtrer les performances.

### B. Interface Réception "Fast-Scan"
* Barre de recherche unique (Omnibox).
* Sélection d'articles par icônes.
* Toggle "Express" déclenchant le nouveau tarif et la priorité.

### C. Gestion des Rayons
* Grille visuelle des emplacements créés par l'agence.
* Indicateur de remplissage en temps réel.

## 3. Design du Ticket Thermique (80mm)
* Header : Logo + Infos Agence.
* Central : **QR CODE Géant** (pour scan au retrait).
* Footer : "Prêt le [Date/Heure]" (SLA automatique).
