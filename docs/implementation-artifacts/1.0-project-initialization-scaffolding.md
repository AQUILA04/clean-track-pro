## Story

As a Developer,
I want to initialize the project repository and development environment,
so that the team has a stable foundation to build features upon.

## Acceptance Criteria

1. **Given** A fresh git repository
2. **When** I initialize the Monorepo (or separate projects) for Backend (NestJS) and Frontend (Next.js)
3. **Then** The basic "Hello World" applications start successfully
4. **And** Docker Compose is configured to launch PostgreSQL and Keycloak containers locally

## Tasks / Subtasks

- [x] Initialize Project Structure
  - [x] Initialize Git repository (if not already done)
  - [x] Set up Monorepo structure (Nx is recommended based on project needs, or standard directories)
  - [x] Create `.gitignore` tailored for Node/NestJS/Next.js

- [x] Initialize Backend (NestJS)
  - [x] Generate NestJS application in `backend/` (or `apps/backend` if using Nx)
  - [x] Validate standard NestJS modular architecture structure
  - [x] Verify application starts on default port (e.g., 3000)

- [x] Initialize Frontend (Next.js)
  - [x] Generate Next.js 14 application in `frontend/` (or `apps/frontend` if using Nx)
  - [x] Ensure App Router and Tailwind CSS are configured
  - [x] Verify application starts on default port (e.g., 4200 or 3001)

- [/] Configure Docker Infrastructure
  - [x] Create `docker-compose.yml` at project root
  - [x] Configure PostgreSQL Service (Version 16+)
    - [x] Set up environment variables for DB credentials
  - [x] Configure Keycloak Service
    - [x] Use Quay.io image (latest/24.x)
    - [x] Configure start-dev mode for local development
  - [x] Configure Redis Service (as per Architecture)
  - [x] Verify `docker-compose up` launches all services correctly

## Dev Notes

- **Architecture Compliance:**
  - **Stack:** NestJS (Backend), Next.js 14 + Tailwind CSS (Frontend).
  - **Database:** PostgreSQL (Prepare for RLS - Row Level Security).
  - **Auth:** Keycloak (OIDC).
  - **Infrastructure:** Docker Compose for local dev.

- **Project Structure Notes:**
  - Ensure clear separation between Backend and Frontend code.
  - If using Nx, ensure `apps/` and `libs/` structure is respected.
